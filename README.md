# برنامج الترجمة المحلي بالكامل (English → Arabic Offline Translator)

برنامج ترجمة آلي عصبي محلي **100% بدون إنترنت** يعمل بكفاءة وسرعة فائقة على أنظمة **Windows** و **Linux**.
يجمع بين الترجمة إلى **اللغة العربية الفصحى** ولغة **الفرانكو / العربيزي (Arabizi)** مع واجهة ويب عصرية وواجهة مكتبية.

---

## 🪟 التشغيل على نظام ويندوز (Windows) بنقرة واحدة:

1. تأكد من تثبيت **[Python 3](https://www.python.org/downloads/)** مع تحديد خيار `Add Python to PATH` أثناء التثبيت.
2. انقر نقراً مزدوجاً على ملف التثبيت التلقائي:
   👉 **`install_windows.bat`**
   *(يقوم بإنشاء البيئة الافتراضية venv وتثبيت الحزم المطلوبة وتثبيت النموذج تلقائياً دون الحاجة لكتابة أوامر).*
3. للتشغيل المباشر:
   * **واجهة الويب العصرية (HTML):** انقر نقراً مزدوجاً على 👉 **`run_web.bat`** وسيفتح المتصفح تلقائياً على `http://127.0.0.1:8765`.
   * **الواجهة المكتبية (Desktop GUI):** انقر نقراً مزدوجاً على 👉 **`run_gui.bat`**.

---

## 🐧 التشغيل على نظام لينكس (Linux):

```bash
# إنشاء وتفعيل البيئة وتثبيت المتطلبات
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# تثبيت النموذج المحلي
python3 install_model.py translate-en_ar-1_0.argosmodel

# تشغيل واجهة الويب
./run_web.sh
```

---
يعتمد البرنامج على محرك **Argos Translate** المفتوح المصدر، ويحتوي على واجهة رسومية بسيطة وسريعة مبنية باستخدام **Python** و **Tkinter**.

## 🌟 المميزات الرئيسية

1. **محلي بالكامل (100% Offline):** بعد تثبيت النموذج لأول مرة، يعمل البرنامج دون الحاجة لأي اتصال بالإنترنت أو الاعتماد على خدمات خارجية مثل Google Translate أو أي Cloud API.
2. **واجهة رسومية خفيفة وسهلة (Tkinter):**
   - مربع لإدخال النص الإنجليزي مع عداد للأحرف والكلمات.
   - زر **Translate** للترجمة.
   - مربع لعرض النص العربي مع محاذاة من اليمين إلى اليسار (RTL).
   - زر **Copy** لنسخ الترجمة النظيفة مباشرة إلى الحافظة.
   - زر **Clear** لمسح النصوص بنقرة واحدة.
3. **عدم تجمّد الواجهة (Asynchronous Threading):** تتم عمليات الترجمة في خيط معالجة منفصل (Background Thread)، مما يضمن بقاء الواجهة مستجيبة وسلسة أثناء الترجمة مع شريط تقدم واضح.
4. **دعم النصوص الطويلة:** تقسيم ذكي وتلقائي للفقرات والجمل الطويلة لتفادي حدود أطوال الرموز (Tokens) في نموذج الذكاء الاصطناعي والحفاظ على تنسيق الأسطر.
5. **معالجة غياب النموذج بأمان ووضوح:** إذا لم يكن النموذج مثبتاً، يعرض البرنامج تنبيهاً إرشادياً واضحاً يوضح كيفية تثبيته، بدلاً من محاولة الاتصال بالإنترنت سراً أو الانهيار.
6. **دعم اللغة العربية في لينكس:** تهيئة الحروف العربية المترابطة وضبط اتجاه القراءة تلقائياً.

## 📦 تنزيل وتثبيت نموذج الترجمة (English → Arabic)

تحتاج لتنفيذ هذه الخطوة **لمرة واحدة فقط** أثناء توفر اتصال بالإنترنت:

### الطريقة الأولى: التنزيل التلقائي عبر السكربت (أثناء توفر الإنترنت)

```bash
python3 install_model.py
```

يقوم السكربت بالاتصال بمستودع حزم Argos Translate وتنزيل نموذج `en_ar` وتثبيته محلياً في مسار المستخدم `~/.local/share/argos-translate`.

### الطريقة الثانية: التثبيت دون اتصال من ملف محلي (.argosmodel)

إذا كان لديك ملف النموذج جاهزاً مسبقاً على فلاش ميموري أو مسار محلي، يمكنك تثبيته دون إنترنت تماماً:

```bash
python3 install_model.py /path/to/translate-en_ar.argosmodel
```

### فحص حالة النموذج

للتحقق من جاهزية النموذج في أي وقت:

```bash
python3 install_model.py --check
```

## ⌨️ اختصارات لوحة المفاتيح في الواجهة

- **Ctrl + Enter:** تنفيذ الترجمة مباشرة للنص المكتوب.
- **زر Copy:** نسخ النص العربي الأصلي الصالح للصق السليم في المتصفحات ومحررات النصوص.
- **زر Clear:** تفريغ المربعين لإدخال نص جديد.

## 🔌 الاستخدام البرمجي في مشاريع بايثون أخرى (Python Library)

إذا كان لديك برنامج بايثون آخر وتريد استدعاء الترجمة منه مباشرة كدالة ترجع النص المترجم:

### الملف المخصص: [`simple_translator.py`](file:///home/jalal/offline_translator/simple_translator.py)

#### مثال على الاستخدام:

```python
from simple_translator import translate

# ترجمة نص مباشر
arabic_text = translate("Hello, welcome to offline translation!")
print(arabic_text)
# الناتج: مرحبا بكم في الترجمة الخارجية!
```

#### أو باستخدام الكائن (Class):

```python
from simple_translator import OfflineTranslator

translator = OfflineTranslator(from_lang="en", to_lang="ar")
arabic_text = translator.translate("Python is great.")
print(arabic_text)
```

يمكن تجربة مثال كامل عبر تشغيل:
