# TurboTranslator Arabic ⚡ (المترجم فائق السرعة للغة العربية)

نسخة مخصصة من محرك الترجمة الفائق **TurboTranslator** تقوم بالترجمة من الإنجليزية إلى **اللغة العربية الأصلية (عربي فصحى عادي)** بدلاً من الفرانكو/العربيزي، مع الحفاظ على نفس السرعة الفائقة وسلامة بنية ملف الـ JSON بنسبة 100%.

---

## 🚀 المميزات الأساسية

1. **كتابة لغة عربية عادية:** ترجمة عربية مفهومة ومقروءة ومباشرة بدون أي حروف لاتينية أو أرقام فرانكو.
2. **السرعة القصوى عبر CTranslate2 & SentencePiece:** تشغيل النموذج مباشرة على نواة C++ مع دعم التكميم (int8) والدفعات (Batch Translation حتى 128 نصاً دفعة واحدة).
3. **كاش منفصل للغة العربية (`translation_cache.json`):** يتم حفظ الترجمات العربية تلقائياً بحيث لا تعيد ترجمة أي نص تم ترجمته مسبقاً، ولا يختلط بكاش الفرانكو.
4. **حفظ تلقائي للتقدم (Auto-Checkpoint):** في حال إيقاف البرنامج مؤقتاً بـ (Ctrl+C) أو إغلاق الجهاز، يتم حفظ كل شيء وتستأنف من نفس النقطة تماماً.
5. **سلامة ملف الـ JSON:** معالجة ذكية لعلامات التنصيص المزدوجة `"` والرموز الخاصة بالألعاب (`<NO TEXT>`, `<CHARNAME>`, إلخ).

## 💻 طريقة الاستخدام

المسار: `/home/jalal/offline_translator/fast_translator_arabic`

### 1. التشغيل الافتراضي المباشر
```bash
cd /home/jalal/offline_translator/fast_translator_arabic
./run.sh
```
* سيقرأ الملف: `../dialog.json`
* سينتج الملف: `dialog_arabic.json`
* سيحفظ الكاش في: `translation_cache.json`

---

### 2. تحديد ملفات مخصصة أو حجم دفعة مخصص
```bash
./run.sh -i ../dialog.json -o ../dialog_arabic_complete.json -b 128
```

---

## 📊 الخيارات المتاحة (CLI Options)

| الخيار | الافتراضي | الوصف |
| :--- | :--- | :--- |
| `-i`, `--input` | `../dialog.json` | مسار ملف الإدخال المطلوب ترجمته |
| `-o`, `--output` | `dialog_arabic.json` | مسار ملف الإخراج النهائي (بالعربية) |
| `-b`, `--batch-size` | `128` | عدد النصوص في الدفعة الواحدة |
| `--cache` | `translation_cache.json` | مسار ملف الكاش لحفظ الترجمات العربية |
| `--inter-threads` | `2` | عدد العمليات المتزامنة في CTranslate2 |
| `--intra-threads` | `2` | عدد خيوط المعالجة الداخلية |
| `--model-dir` | تلقائي | مسار مجلد النموذج إن أردت تحديده يدوياً |
