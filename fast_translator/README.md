# TurboTranslator ⚡ (المترجم فائق السرعة للغة الفرانكو/العربيزي)

برنامج جديد تماماً ومستقل مصمم لترجمة ملفات الألعاب الضخمة (`dialog.json`) من الإنجليزية إلى الفرانكو (Arabizi) بأقصى سرعة ممكنة وبأعلى درجات الأمان لبنية الـ JSON.

---

## 🚀 لماذا هو أسرع من `lord.py` بأكثر من 15x إلى 30x ضعف؟

1. **الترجمة بالدفعات (Batch Translation):** يرسل حتى **128 نصاً دفعة واحدة** إلى محرك الترجمة بدلاً من ترجمة سطر بسطر.
2. **محرك CTranslate2 و SentencePiece المكتوبين بلغة C++:** تخطي طبقات بايثون الثقيلة في مكتبة Argos واستدعاء دوال C++ المترجمة مسبقاً مباشرة.
3. **التخلص من عبء مكتبة Stanza:** كان `lord.py` يستدعي نموذج Stanza لتقسيم الجمل لكل سطر مما يهدر ثوانٍ كاملة في كل عملية، بينما البرنامج الجديد يقوم بالتقسيم الذكي بدون Stanza.
4. **تخطي التكرارات (Deduplication & Caching):** ملفات الحوارات بها أكثر من **20,000 نص مكرر** (مثل عناوين الأسلحة والخيارات)؛ البرنامج يترجم النص مرة واحدة ويستخدمه فوراً دون إعادة الحساب عبر الذكاء الاصطناعي.
5. **جدولة النصوص حسب الطول (Length Bucketing):** تجميع الجمل المتقاربة في الطول معاً لتجنب حشو المصفوفات (Zero-padding) وإهدار موارد المعالج.
6. **تحويل الفرانكو بلغة C:** استخدام `str.maketrans` الذي يعمل بالكامل على مستوى لغة C في ميكروثوانٍ.

---

## 🛠️ تصحيح أخطاء البرنامج القديم

* **إصلاح تلف ملف JSON:** كان `lord.py` يُدرج علامات التنصيص المزدوجة `"` داخل النصوص دون تهريب (`\"`) مما يجعل الملف تالفاً برمجياً. تم إصلاح هذا بالكامل ليصبح ملف المخرجات مطابقاً لمواصفات JSON القياسية بنسبة 100%.
* **حفظ التقدم التلقائي (Auto-Checkpoint):** يحفظ البرنامج ترجماته في ملف كاش `translation_cache.json`. إذا تم إيقاف البرنامج (Ctrl+C) أو أُغلق الجهاز، سيبدأ فوراً من حيث توقف دون إعادة ترجمة أي نص سابق.

## 💻 طريقة الاستخدام

المجلد الحالي: `/home/jalal/offline_translator/fast_translator`

### 1. التشغيل القياسي
```bash
cd /home/jalal/offline_translator/fast_translator
./run.sh
```
سيقوم بقراءة `../dialog.json` وحفظ النتيجة في `dialog_arabizi.json`.

---

### 2. التشغيل باللغة العربية العادية (بدون فرانكو)
إذا أردت مخرجات باللغة العربية الفصحى العادية بدلاً من الفرانكو:
```bash
./run_arabic.sh
# أو عبر تمرير العلم --arabic:
./run.sh --arabic
```
* سيتم حفظ النتيجة في: `dialog_arabic.json`
* وسيتم حفظ الكاش تلقائياً في: `translation_cache_arabic.json`

---

### 3. التشغيل مع استيراد ما تم إنجازه سابقاً من `test.json` (توفير ساعات العمل السابقة)
إذا كنت تريد الاستفادة من الـ 7,500 سطر التي ترجمها `lord.py` بالفعل دون إعادة ترجمتها:
```bash
./run.sh --import-from ../test.json
```

---

### 4. خيارات مخصصة
```bash
# تحديد ملف إدخال وإخراج مختلفين وحجم دفعة مخصص:
./run.sh -i ../dialog.json -o ../my_translated_dialog.json -b 128
```

## 📊 الخيارات المتاحة (CLI Options)

| الخيار | الافتراضي | الوصف |
| :--- | :--- | :--- |
| `-i`, `--input` | `../dialog.json` | مسار ملف الإدخال المطلوب ترجمته |
| `-o`, `--output` | تلقائي (`dialog_arabizi.json` أو `dialog_arabic.json`) | مسار ملف الإخراج النهائي |
| `--arabic`, `-ar` | `False` | تفعيل الترجمة للغة العربية العادية مباشرة بدون فرانكو |
| `--mode` | `arabizi` | نمط الترجمة (`arabizi` للفرانكو أو `arabic` للعربي العادي) |
| `-b`, `--batch-size` | `128` | عدد النصوص المترجمة في الدفعة الواحدة (64 إلى 128) |
| `--import-from` | `None` | مسار ملف سابق لاستيراد الترجمات منه (مثل `../test.json`) |
| `--cache` | تلقائي (`translation_cache.json` أو `_arabic.json`) | مسار ملف حفظ الكاش لاستئناف العمل |
