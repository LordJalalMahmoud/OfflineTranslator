# TurboTranslator Web ⚡ (المترجم فائق السرعة - واجهة الويب الأوفلاين)

برنامج مترجم عصري متكامل بصفحة **HTML تفاعلية فائقة الجمال والسرعة**، يعمل **بدون إنترنت تماماً (100% Offline)**، ويجمع بين قدرات برنامجي:
1. **Fast Translator**: للترجمة إلى لغة الفرانكو / العربيزي (Arabizi).
2. **Fast Translator Arabic**: للترجمة إلى اللغة العربية الفصحى الأصلية.

---

## 🌟 أبرز مميزات البرنامج

* 🔒 **بدون إنترنت 100% (Zero Internet Required):** لا يتصل بأي خوادم خارجية، ولا يعتمد على أي شبكات أو خطوط CDN خارجية. كل شيء (الأيقونات SVG، الخطوط، الأنماط) مدمج ومحلي تماماً.
* ⚡ **محرك C++ فائق السرعة (CTranslate2 & SentencePiece):** سرعة استجابة مذهلة مع استهلاك خفيف للموارد بفضل التكميم (int8 CPU).
* 💾 **كاش ضخم بأكثر من 93,000 ترجمة جاهزة:** استرجاع فوري للترجمات المكررة في أقل من **0.05 مللي ثانية**.
* 🌟 **نمط العرض المزدوج (Dual Output):** يعرض الترجمة العربية الفصحى وترجمة الفرانكو جنباً إلى جنب في نفس اللحظة لمقارنتها بكل سهولة.
* 🎮 **ترجمة ملفات الألعاب الضخمة (`dialog.json`):**
  * ترجمة بالدفعات (Batching حتى 128 نصاً في المرة).
  * شريط تقدم تفاعلي مع عداد السرعة (سطر/ثانية) والوقت المتبقي.
  * نافذة مراقبة حية للأسطر المترجمة لحظة بلحظة.
  * حماية بنية ملف الـ JSON ورموز الألعاب الخاصة (`<NO TEXT>`, `<CHARNAME>`).
* 🎙️ **نطق صوتي مدمج (Offline TTS):** استماع فوري للنصوص عبر محرك النطق المحلي للمتصفح.
* 📋 **نسخ بنقرة واحدة:** زر نسخ سريع مع إشعارات عائمة (Toast Notifications).
* 🌓 **المظهر الداكن والفاتح (Dark/Light Mode):** تصميم زجاجي عصري (Glassmorphism) مريح للعين مع حفظ تفضيلاتك محلياً.

## 📑 أقسام الواجهة

1. **المترجم الفوري (Text Translator):**
   * كتابة النصوص بالإنجليزية والترجمة الفورية أثناء الكتابة (Live Translation) أو عبر `Ctrl+Enter`.
   * التبديل بين: (عرض مزدوج عربي + فرانكو) أو (عربي فقط) أو (فرانكو فقط).
   * أمثلة جاهزة لحوارات الألعاب ووصف الأسلحة والمهام.
   * سجل محفوظ محلياً لآخر 20 ترجمة قمت بها.

2. **مترجم ملفات الألعاب (Batch File Translator):**
   * اختيار مباشر لملف `dialog.json` أو رفع أي ملف `.json` أو `.txt` أو `.srt`.
   * اختيار نمط الإخراج (عربي فصحى أو فرانكو).
   * زر تحميل مباشر للملف المترجم فور الانتهاء.

3. **محول الفرانكو المباشر (Franco Converter):**
   * أداة كتابة سريعة لتحويل أي نص عربي إلى فرانكو فوراً بدون الذكاء الاصطناعي عبر كود C السريع.
   * جدول دليل الحروف والأرقام (7 = ح، 3 = ع، 2 = ء، إلخ).

4. **مستكشف الكاش (Cache Explorer):**
   * محرك بحث سريع يبحث داخل الـ 93,000 ترجمة المخزنة محلياً ويستعرض النص الإنجليزي ومقابله العربي والفرانكو فوراً.

5. **معلومات المحرك (Engine Info):**
   * تفاصيل النموذج العصبي وحالة المعالج والكاش.
